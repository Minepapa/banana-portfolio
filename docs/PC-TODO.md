## 1. GAS — VIP 펀드 기준가 자동갱신 복구 (우선)

**증상:** `연금저축!F15`가 6/2 기준가(2,217)에서 멈춤. 6/3·6/4·6/5 값이 API엔 있는데 시트 미반영 → 3일째 갱신 정지.
**원인 추정:** API·파싱 로직은 정상(수동 호출 시 오늘 2,234 정상 반환). **GAS 시간 트리거가 6/2 이후 실패 또는 자동 해제**된 것으로 보임.

점검 순서 (Apps Script 에디터):
1. **실행(Executions)** 화면 → `updateAllPrices`/`updateVipFundPrice`가 6/2 이후 빨간 에러로 실패했는지 확인.
2. **트리거(Triggers)** 화면 → 시간 기반 트리거가 살아있는지(삭제·비활성·한도초과 자동해제 여부).
3. 트리거 없으면 재등록: `updateAllPrices` · 시간 기반 · 1시간마다.
4. `updateVipFundPrice` 수동 1회 실행 → F15가 2,234로 바뀌는지 확인.
