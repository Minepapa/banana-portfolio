# banana-portfolio — 실전 사용 가이드

> 내가 만든 앱을 내가 잘 쓰기 위한 실전 가이드. **각 탭을 언제·어떻게 쓰고, 자산 관리에 어떻게 녹이나**에 집중한다.
> 기능별 역할·구조 정의는 [FEATURES.md](../FEATURES.md) 참조. 이 문서는 "쓰는 법".

**탭 순서**: 홈 · 오늘 · 리포트 · 리스크 · 포지션 · 평가 · 보유종목 · 자산분배 · 체결 · 배당금 · 수익금 · KPI · 도움말

---

## 0. 한눈에 — 루틴 시트

| 언제 | 무엇을 | 어느 탭 |
|------|--------|---------|
| 매일 (제일 먼저) | 오늘 할 일 체크리스트(자동 집계) | **오늘** |
| 매일 아침 1분 | 거시 충격 경보 확인 | **리스크** |
| 주 1회 (월요일) | 논리점검 + 행동처방 | **리스크** → **리포트** |
| 살까 고민 | 사기 전 평가부터 | **평가 [매수]** |
| 팔까 고민 | 근거 깨졌나 점검 | **평가 [매도]** |
| 보유 점검 | 왜 샀나(투자논리)·언제 팔지(이탈조건) | **포지션** |
| 월/회고 | 성과·습관 점검 | **KPI** |
| 체결/배당 발생 | 자동, 손 안 댐 | 체결/배당금 |

**황금 원칙**: 가격(52주 고점·RSI 과열)만으로 사고팔지 않는다. **평가가 먼저, 주문이 나중.** 펀더멘털 우선.

## 1. 헷갈리는 세 탭 완벽 정리 — 리스크 · 포지션 · 평가

이 세 탭이 서로 연결되어 있어 혼동하기 쉽다. 역할을 한 문장으로 정리하면:

| 탭 | 한 문장 역할 | 내가 하는 행동 |
|----|-------------|--------------|
| **리스크** | 자동 경보를 **읽는** 탭 | 신호 확인만. 여기서 팔지 않는다. |
| **포지션** | 보유 종목의 투자논리를 **관리**하는 탭 | 확인·이탈조건 편집·교훈 기록 |
| **평가** | 매수/매도 **결정을 내리는** 탭 | 평가 의뢰·근거 점검·판정 읽기 |

### 언제 어느 탭으로 가나 — 상황별 흐름

```
아침에 앱을 열었다
│
├─ 오늘 탭에 리스크 경보 표시됨
│   └─→ [리스크] 탭으로: 🟡🔴만 펼쳐서 "자세히"·"근거" 읽기
│         └─ 논거훼손(B 신호)이 있다
│              └─→ [포지션] 탭으로: 이탈조건 대조
│                    └─ 이탈조건에 해당하는가?
│                         ├─ 아직 아님 → 포지션 탭에서 이탈조건 수정, 끝
│                         └─ 해당함 → [평가 [매도]] 탭으로: "근거 점검" 버튼
│
├─ 오늘 탭에 "투자논리 훼손 N종목" 표시됨
│   └─→ [포지션] 탭으로: 🔴 경보 종목 이탈조건 대조
│         └─ 이탈조건 충족 → [평가 [매도]] 탭으로
│
├─ "살까?" 충동이 생겼다
│   └─→ [평가 [매수]] 탭으로: "평가 의뢰" → 큐에 넣고 결과 기다리기
│
└─ "팔까?" 고민이 생겼다
    └─→ [평가 [매도]] 탭으로: 해당 종목 칩 → "근거 점검" 버튼
```

### 핵심 구분

**리스크 탭은 읽기 전용이다.**
- 🟢 정상이면 그냥 닫는다.
- 🟡🔴가 떴다고 바로 팔지 않는다. "조기경보"일 뿐 — 행동은 평가 탭에서.
- 여기서 할 수 있는 것은 아무것도 없다. 읽고 다음 탭으로 넘어가는 것이 전부.

**포지션 탭은 '논리 유지 관리' 탭이다.**
- "왜 샀는지"(투자논리)를 확인하고 동의하는 탭.
- "언제 팔지"(이탈조건)를 업데이트하는 탭.
- 경보가 뜬 종목이 이탈조건에 해당하는지 대조하는 탭.
- 청산 후 "교훈 한 줄"을 남기는 탭.
- **매도 결정을 내리는 탭이 아니다** — 이탈조건에 해당한다고 판단되면 평가 탭으로 넘긴다.

**평가 탭은 유일한 의사결정 탭이다.**
- 매수든 매도든 **실제 주문 전 반드시 거쳐야 하는 관문.**
- [매수] 모드: 새 종목을 큐에 올리면 AI가 5축 평가 카드를 만든다.
- [매도] 모드: "근거 점검" 버튼으로 매도평가 카드를 만들고, 최초 매수 이유가 깨졌는지 확인한다.
- 여기서 🔴부적합이 나왔을 때 비로소 주문을 넣는다.

## 2. 자산관리 루틴 (시나리오 중심)

### ☀️ 매일 — 오늘 탭부터 (행동 체크리스트)
- 앱을 열면 **오늘 탭**이 그날 처리할 거리를 자동 집계한다: 리스크 경보·투자논리 훼손·미처리 체결·확인 대기·반성 필요·리밸런싱 갭·이번 주 처방·무인 잡 점검.
- 각 항목에 **"확인 ✓"** 버튼이 있다. 누르면 카드가 사라지지 않고 체크 표시로 남는다(취소선+흐리게). 모두 확인하면 상단에 "오늘 할 일 모두 완료!" 배너가 뜬다. 확인 상태는 오늘 하루만 유지.
- 자동 소멸 항목(체결·리밸 등)은 처리하면 데이터가 사라져 자연스럽게 없어진다.
- 비어 있으면 "오늘 할 일 없음" → 홈에서 숫자만 확인하면 끝. (구 거래결정 탭을 대체)

### 🌅 매일 아침 1분 — 리스크 탭 훑기
- **risk-d**(평일 **16:30** 자동, 장마감 후)가 **당일 종가**로 거시 충격을 점검해 리스크 탭에 신호를 남긴다 → **다음 개장 전 경보 보장**.
- 🟢 정상이면 **그냥 닫는다.** 🟡 주의·🔴 경보만 펼쳐서 본다.
- 전형 예: "USDKRW 환율 극단값 상단(1,500) 초과 → 달러 자산 축소 검토", "미10년물 급등 → 채권·리츠 점검", "KOSPI 5일 고점 대비 -10% 급락 → 매수 기회 점검".
- **여기서 바로 팔지 않는다.** 경보는 *조기경보*일 뿐. 실제 행동은 평가 탭에서 결정.

### 📅 주 1회 (월요일 아침) — 논리점검 + 행동처방
1. **리스크 탭**: risk-b(월 **07:00** 자동)가 위탁 개별주식 9종목의 펀더멘털 논리훼손을 점검한 신호 확인.
2. **리포트 탭**: 주간 AI 리포트의 "이번 주 행동 처방"(딱 1가지)을 읽는다. 이게 이번 주 실행 항목.
   - 리포트는 **수동 생성**(Trading Agent 스킬) → 시트 적재는 자동. 안 만들면 안 갱신됨.

### 🤔 매수/매도 고민이 들 때 — 평가 먼저, 주문 나중 ★핵심
이 앱의 심장. **평가 탭 하나에서 [매수][매도] 토글**로 전환한다. 순서를 지킨다:
1. **평가 탭 [매수]**: 살까 검토 종목을 "평가 의뢰"로 큐에 올린다.
   **평가 탭 [매도]**: 팔까 검토 종목 칩을 눌러 "근거 점검"으로 매도평가를 돌린다.
2. AI가 평가 카드를 생성(drain 3h 자동, 또는 수동).
3. 카드를 읽고 **최초 매수 이유 대비 현재**를 비교.
4. 판정(🟢유효/🟡관망/🔴부적합)을 보고 **그 다음에** 실제 주문을 넣는다.
- 충동매매 방지 장치. "지금 사고 싶다 → 일단 큐에 넣는다"가 습관이 되게.

### 📊 월/회고 — KPI 탭
- TWR(시간가중수익률)·Sharpe·MDD(최대낙폭)로 성과를 객관적으로 본다.
- **행동추적**: 500만원 원칙(1종목 최대 비중)을 지켰는지, 평가→매수 일치율(평가 없이 산 건 없는지)을 점검.
- 수익률보다 **행동 습관**을 보는 탭.

### 💰 체결·배당이 발생하면 — 자동 (확인만)
- 증권사 카카오 알림 → 알람 탭 적재 → **15분 내** 체결내역/배당금 자동 반영.
- 할 일 없음. 체결/배당금 탭에서 들어왔나 확인만. 종목명이 이상하면 배당 탭에서 인라인 수정.

## 3. 탭별 사용법 (앱 순서대로)

각 탭: **언제 보나 · 무엇을 하나 · 읽는 법 · 팁/주의**

### 홈
- **언제**: 수시, 앱 열면 첫 화면.
- **무엇**: 총자산·평가손익·계좌별 비중 도넛·평가금 추이.
- **읽는 법**: 전체 그림 한눈에. 계좌별 비중 도넛으로 쏠림 확인.
- **팁**: 빠른 현황 체크용. 의사결정은 다른 탭에서.

### 오늘 ★ (매일 처리할 행동 체크리스트)
- **언제 쓰나**: **매일 앱을 열면 첫 행동.** 홈이 *숫자 확인*이라면 오늘 탭은 *행동 유도* — 흩어진 처리거리를 한 화면에 모아준다. (구 거래결정 탭을 대체·확장)
- **무엇이 보이나** — 데이터에서 자동 집계된 항목만(없으면 "오늘 할 일 없음"):
  - **리스크 경보·주의**: 리스크 탭의 🔴🟡 건수.
  - **투자논리 훼손 N종목**: 보유 논리 ↔ 리스크 신호 충돌(포지션·평가[매도]와 동일 소스).
  - **미처리 체결 N건**: 동기화하면 보유종목에 반영.
  - **투자논리 확인 대기 N건**: 매수 전제에 아직 동의 표시 안 한 보유 종목.
  - **반성 필요 N건**: 청산됐는데 교훈 미기록.
  - **리밸런싱 갭 N건**: 목표 비중 ±5%p 초과 자산군(인라인 목록).
  - **이번 주 처방**: 최신 주간 리포트의 행동 처방 1줄.
  - **무인 잡 점검 N건**: 자동화 잡 실패·미실행·정체.
- **무엇을 하나**: 각 항목의 "…보기 ›" 버튼이 해당 탭으로 데려간다. 오늘 탭은 *모으는 허브*, 실제 처리는 각 탭에서.
- **읽는 법**: 각 항목에 **"확인 ✓"** 버튼. 눌러도 카드가 사라지지 않고 체크 표시로 남는다(취소선+흐리게). 모두 확인 시 상단에 완료 배너. 자동 소멸 항목(체결·리밸 등)은 처리하면 데이터가 사라져 자연스럽게 없어진다.
- **주의**: 신규 분석을 하지 않는다 — 리스크·포지션·체결·리밸·리포트의 **기존 데이터를 종합**할 뿐. 실제 주문은 평가 탭을 거친 뒤.

### 리포트
- **언제**: 주 1회(월요일).
- **무엇**: 주간 AI 종합 리포트(읽기 전용). 날짜 선택 + 본문.
- **읽는 법**: "이번 주 행동 처방" 1줄이 핵심. 나머지는 맥락.
- **주의**: **생성은 수동**(Trading Agent 리포팅 스킬 실행). 안 만들면 갱신 안 됨. 적재만 자동(매일 09:00 sync). 처방·논거경보·리밸 갭의 *처리*는 오늘 탭이 이 신호를 재인용해 모아 보여준다.

### 리스크 ★ (읽는 탭 — 여기서 팔지 않는다)
- **언제 쓰나**: **매일 아침 1분**. 무인 조기경보를 훑는 용도. 손대는 탭이 아니라 *보는* 탭.
- **무엇이 보이나**:
  - 요약 카드 3개: 🔴 경보 / 🟡 주의 / 🟢 정상 건수.
  - 신호별: **유형(D=거시 / B=논리)** · 대상(종목·지수) · 신호(🟢🟡🔴) · 요약 · 자세히(detail) · 근거(evidence) · 기준선참조.
  - **D(거시)**: risk-d가 평일 **16:30**(장마감 후) 생성. 환율·금리·지수 충격 등 *일간 조기경보*. 당일 종가로 판단해 다음 개장 전에 도착.
  - **KOSPI 급락 결정론 가드레일**: 코스피가 최근 **5거래일 고점 대비 -10% 이하**로 빠지면 LLM 판단과 무관하게 🔴 **강제 경보**. 네이버 비지연 종가를 써서 진행 중 급락도 지연 없이 잡는다.
  - **B(논리)**: risk-b가 **월 07:00** 생성. 위탁 9종목 펀더멘털 훼손 *주간 점검*. 리스크기준선(매출총이익·영익·ROE(TTM)·부채·EPS) 대비 악화 감지.
- **읽는 법**: 🟢는 무시, 🟡🔴만 펼쳐 '자세히'·'근거' 확인.
- **다음 행동**: 🟡🔴 B신호가 있다 → [포지션] 탭으로. 🟡🔴 D신호가 있다 → 이번 주 처방과 연결해 생각, 행동이 필요하면 [평가 [매도]]로.
- **주의**: 리스크 탭은 **신호만**(행동 권고 없음). 경보가 떠도 **바로 팔지 않는다** → 포지션에서 이탈조건 대조 → 평가 탭에서 의사결정.

### 포지션 ★ (투자논리 관리 탭 — 이탈조건 대조 후 평가로 넘긴다)
- **언제 쓰나**:
  1. 리스크 탭에서 B(논리훼손) 신호를 확인한 직후 → **이탈조건과 대조**하러.
  2. 새로 적재된 보유종목의 **AI 초안 투자논리에 동의** 표시(확인 버튼)하러.
  3. **이탈조건을 업데이트**하거나 고치러.
  4. 청산 후 **교훈 한 줄**을 기록하러.
- **무엇이 보이나**:
  - **확신형**(개별주): 논리 훼손(risk-b 신호)으로 감시. / **배분형**(자산군 대표 ETF): 비중 드리프트로 감시.
  - 카드 펼치면: 투자논리 · 목표 · 이탈조건 · 예상보유 · 진입일 · 최근 논리 점검일.
  - **🔴 논거 훼손 경보**(빨강 배지·테두리): 보유 투자논리가 리스크 신호와 충돌 → 이탈조건과 대조해 매도 검토. (평가[매도]·오늘 탭과 동일 판정)
  - **청산 · 반성**: 매도된 종목은 자동 청산 처리(매일 16:00 journal-sync) → **교훈 한 줄** 기록.
- **무엇을 하나**:
  - **투자논리 확인**: AI 초안에 동의하면 "이 투자논리 확인" → 확인 배지. (앱에서 직접 수정도 가능)
  - **이탈조건 편집**: 카드에서 인라인 수정 → 시트 H·P열 저장.
  - **교훈 기록**: 청산 카드에 한 줄 → 다음 매수 때 '반성 필요'로 재노출.
- **다음 행동**: 🔴 경보 종목의 이탈조건이 충족됐다 → [평가 [매도]] 탭으로 "근거 점검" 실행.
- **주의**: 투자논리는 **AI 초안**이다. 길게 안 써도 됨 — 확인만 누르거나 한 줄 고치면 충분. **여기서 매도 결정을 내리지 않는다** — 판단은 평가 탭에서.

### 평가 ★ (유일한 의사결정 탭 — 매수·매도 모두 여기서 결정)
- **상단 [매수][매도] 토글로 모드 전환.** 매수든 매도든 **주문 전 반드시 이 탭을 거친다.**

**[매수] 모드** — 새 종목 매수를 검토할 때
- **언제 쓰나**: 새 종목 매수 검토, 추가매수 전 "지금 사도 되나" 확인. 충동적으로 사고 싶을 때 **일단 여기에 넣는 것**이 핵심 습관.
- **무엇을 하나**:
  1. "평가 의뢰" 버튼 → 모달에서 **종목명 + 시장(KR/US) + (선택)메모** 입력 → "큐에 추가".
  2. 평가요청 큐에 `대기` 상태로 들어감 → drain(3h 자동)이 평가 카드 생성 → 종목투자노트에 카드 적재.
- **숫자는 Node가, 판단은 AI가** (결정론 파이프라인):
  - PER·ROE(TTM)·RSI(14)·52주 위치·PBR·영업이익률·FCF yield 등 지표는 **코드 페처**(pykrx·yfinance·OpenDart)가 직접 산출해 카드에 주입한다. AI는 **Read 전용**으로 5축 *판단*만 한다 — AI가 숫자를 지어내지 않는다.
  - 각 지표 값엔 **출처**(네이버·yfinance·OpenDart)가 붙어 검증 가능.
  - 못 구한 축은 **"(데이터 부족)"**으로 표기, 추정하지 않는다.
- **읽는 법**: 큐 상태 뱃지(`대기`·`처리중`·`완료`·`오류`). 종목 칩에 최신 등급. 5축(수익성·안정성·밸류에이션·현금흐름·모멘텀) → 종합 🟢유효 / 🟡관망 / 🔴부적합.
- **주의**: 큐가 비면 아무 일도 안 함(자동 종목 추가 없음). 평가는 **내가 큐에 넣어야** 돌아간다.

**[매도] 모드** — 보유 종목을 팔까 점검할 때
- **무엇이 뜨나**: **평가 이력이 있고 + 현재 보유 중**인 종목만. (평가만 하고 안 산 종목, 전량 매도한 종목은 안 뜸)
- **언제 쓰나**: 포지션 탭에서 이탈조건이 충족됐다고 판단됐을 때. 또는 회고·근거 점검(왜 샀고 그 이유가 유효한가).
- **읽는 법**:
  - 종목 칩 클릭 → 보유 현황 + **최초 매수 근거** + 평가 이력 타임라인.
  - **논거 훼손 경보**(🔴, 카드 상단·칩에 표시): 보유 투자논리가 리스크 신호와 충돌. **포지션·오늘 탭과 동일한 소스**라 어디서 봐도 같은 판정.
  - **기술적 신호**(🟡, 별도 박스): RSI 과열(>70)·급락(<30)·52주 고점(>80%). 논거 훼손과 구분해 표시 — 가격 신호는 참고용.
  - 평가 경과일: >30일 🟡, >90일 🔴.
  - **"근거 점검" 버튼** = 매도평가 트리거. 평가요청 큐에 `메모='매도 평가'`로 적재 → drain이 sell-evaluation 카드 생성. *최초 매수 이유가 있어야* 활성화.
- **핵심 용도**: 매도 결정의 기준선. "샀을 때 이유가 깨졌나"를 보고 판다. 가격이 올라서/내려서가 아니라.

### 보유종목
- **언제**: 수시.
- **무엇**: 4계좌 통합 보유 현황(종목·수량·평균단가·수익률).
- **읽는 법**: 자산군별 색상. 수익률 정렬로 손실 종목 식별.
- **팁**: 해외주식 평균단가는 **USD**로 표시(달러값 그대로).

### 자산분배
- **언제**: 리밸런싱 판단 시.
- **무엇**: 계좌별(위탁/연금저축/ISA/IRP) 목표 vs 현재 비중, 리밸 갭.
- **읽는 법**: 목표% 대비 현재% 갭(+/-)이 크면 조정 후보. **현금성 예수금은 비중에서 제외**(자산군 100% 기준).
- **주의**: 갭이 있다고 바로 매매하지 말 것. 갭 + 평가(펀더멘털)를 같이 본다. 갭은 오늘 탭 '리밸런싱 갭' 항목에도 모인다.

### 체결 / 배당금 / 수익금
- **언제**: 거래·배당 발생 후 확인.
- **무엇**: 체결내역(매수/매도)·배당 수령·실현손익. 체결 탭은 최신 거래가 위에 표시.
- **읽는 법**: 자동 적재(15분 주기). 수동 개입 불필요.
  - **체결**: 해외주식 체결가는 **$**, 국내는 **₩** 표시. 셀 미완성 행은 길게 눌러(우클릭) 편집.
  - **수익금**: 해외주식은 매수·매도단가 **USD**, 수익금 합계는 **KRW**(×환율 자동 환산). 국내는 전부 ₩.
- **팁(배당)**: 배당 탭은 **종목명 인라인 편집** 가능. 증권사 알림 종목명이 약칭/오타일 때 직접 수정.
- **팁(체결)**: 국내주식 매수/매도 시 ISA·위탁 예수금 자동 증감. 해외주식은 외화 RP에서 USD 자동 가감.

### KPI
- **언제**: 월/분기 회고.
- **무엇**: TWR·Sharpe·MDD + 행동추적(500만 원칙 준수·평가→매수 일치율) + 무인 잡 상태.
- **읽는 법**: 성과 지표 + **습관 지표**를 같이. 평가 없이 산 종목이 있으면 행동추적에 잡힌다.

## 4. 자주 하는 작업 (How-to)

### 새 종목 매수 검토
1. **평가 탭 [매수]** → "평가 의뢰" → 종목명·시장 입력 → "큐에 추가".
2. 기다리거나(drain 3h) 수동 drain. 완료되면 카드 확인.
3. 5축 종합 🟢이면 매수 후보, 🟡 관망/절반, 🔴 매수금지.

### 매도 판단
1. **오늘 탭** → "투자논리 훼손" 항목 확인 → **포지션 탭**으로.
2. 🔴 경보 종목 카드 펼쳐 **이탈조건 대조** → 충족 여부 판단.
3. 충족됐으면 **평가 탭 [매도]** → 해당 종목 칩 → "근거 점검" 버튼.
4. 매도평가 카드에서 **최초 매수 이유가 깨졌는지** 확인.
5. 🔴부적합이면 매도 실행. 🟢유효면 보유 유지(가격이 빠져도 논리가 멀쩡하면 안 판다).

### 보유 종목 투자논리·이탈조건 점검
- **포지션 탭** → 카드 펼쳐 투자논리 확인(동의하면 "이 투자논리 확인" 버튼), 이탈조건 인라인 편집.
- 🔴 논거 훼손 경보가 뜬 종목은 이탈조건과 대조해 평가 탭 [매도]로 넘어간다.

### 배당 종목명이 틀렸을 때
- **배당 탭**에서 종목명 셀 인라인 편집. (증권사 알림 약칭/오타 보정)

### 리밸런싱 갭 확인
- **자산분배 탭** 목표% vs 현재% 갭 확인 → 갭 큰 자산군 + 평가(펀더멘털) 같이 보고 조정. 오늘 탭 '리밸런싱 갭' 항목에서 갭 목록을 한 번에 본다.

## 5. 데이터 흐름 · FAQ

전체 데이터 흐름·자동화 잡 정의는 [FEATURES.md](../FEATURES.md) 참조. 사용자 관점 FAQ만:

- **체결/배당이 바로 안 떠요** → 정상. 알람 탭 적재 후 parse-notifications(15분 주기)가 채운다. 최대 15분 지연.
- **평가가 안 돌아가요** → 큐가 비었거나 drain(3h) 차례가 안 됨. 또는 헤드리스 claude 사용량 한도(로그 확인).
- **평가 [매도]에 종목이 안 떠요** → 평가 이력이 있고 + 현재 보유 중인 종목만 뜬다. 평가만 하고 안 샀거나 전량 매도했으면 안 보임.
- **같은 종목인데 탭마다 판정이 달라요** → 논거 훼손 경보는 평가[매도]·포지션·오늘 **모두 동일 소스**(findThesisAlerts). RSI/52주 '기술적 신호'는 별도 박스라 혼동 없음.
- **평가 카드에 "(데이터 부족)"이 떠요** → 정상이다. 숫자는 Node 페처가 산출하는데 해당 지표를 못 구하면 AI가 추정하지 않고 공백으로 둔다. 종목코드·티커 매핑이 실패하면 그 축 전체가 데이터 부족으로 빠진다.
- **코스피가 급락했는데 알림이 늦어요** → risk-d가 장마감 후(16:30) 당일 종가로 돌고, KOSPI가 5거래일 고점 대비 -10% 이하면 LLM 없이도 🔴 강제 경보가 그날 저녁 나간다(네이버 비지연 종가).
- **해외주식 단가가 이상해요** → 단가는 USD, 합계는 KRW(×환율)가 정상. 체결가는 $로 표시.
- **리스크 신호가 안 갱신돼요** → risk-d는 평일 **16:30**(장마감 후), risk-b는 **월 07:00**에만 실행. 사용량 한도 시 일부 실패 가능.
- **리포트가 갱신 안 돼요** → 생성이 수동이다. Trading Agent 리포팅 스킬을 돌려야 새 리포트가 생긴다.
- **포지션 탭에서 논거 훼손인데 바로 팔아야 하나요** → 아니다. 포지션은 이탈조건 대조 탭. 이탈조건 충족 여부를 판단한 뒤, 충족됐으면 평가 탭 [매도]로 넘겨서 매도평가 카드를 돌린다. 경보 = 팔아라가 아니다.
- **리스크 B 신호가 월요일에만 업데이트되면 화~일은 어떻게 하나요** → 주 1회 스냅샷이다. 중간에 뭔가 터지면 리스크 D(매일 16:30)가 거시 충격을 잡는다. 개별 종목 펀더멘털은 분기 단위로 변하므로 주 1회도 충분하다.

## 6. 투자 원칙 리마인더

> 정본은 Trading Agent. 여기선 앱 쓰며 잊지 말 것만.

1. **펀더멘털 우선, 가격 후순위.** 52주 고점·RSI 과열만으로 익절하지 않는다.
2. **평가 먼저, 주문 나중.** 충동매매는 일단 평가 [매수] 큐로.
3. **매도는 논리 훼손으로.** 평가 [매도]의 "최초 매수 이유"가 깨졌을 때 판다. 가격 등락이 아니라.
4. **500만원 원칙.** 1종목 비중 한도. KPI 행동추적에서 점검.
5. **리스크 경보 ≠ 행동 지시.** 조기경보는 보는 것, 결정은 평가 탭에서.
6. **리스크 → 포지션 → 평가 순서.** 경보를 보면 → 이탈조건을 대조하고 → 판단은 평가 탭에서.
