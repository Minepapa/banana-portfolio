# banana-portfolio — 실전 사용 가이드

> 내가 만든 앱을 내가 잘 쓰기 위한 실전 가이드. **각 탭을 언제·어떻게 쓰고, 자산 관리에 어떻게 녹이나**에 집중한다.
> 기능별 역할·구조 정의는 [FEATURES.md](../FEATURES.md) 참조. 이 문서는 "쓰는 법".

**탭 순서**(사용 빈도순): 홈 · 리스크 · 매수평가 · 매도검토 · 보유종목 · 자산분배 · 리포트 · KPI · 체결 · 배당금 · 수익금

---

## 0. 한눈에 — 루틴 시트

| 언제 | 무엇을 | 어느 탭 |
|------|--------|---------|
| 매일 아침 1분 | 거시 충격 경보 확인 | **리스크** |
| 주 1회 (월요일) | 논리점검 + 행동처방 | **리스크** → **리포트** |
| 살까 고민 | 사기 전 평가부터 | **매수평가** |
| 팔까 고민 | 근거 깨졌나 점검 | **매도검토** |
| 월/회고 | 성과·습관 점검 | **KPI** |
| 체결/배당 발생 | 자동, 손 안 댐 | 체결/배당금 |

**황금 원칙**: 가격(52주 고점·RSI 과열)만으로 사고팔지 않는다. **평가가 먼저, 주문이 나중.** 펀더멘털 우선.

## 1. 자산관리 루틴 (시나리오 중심)

### 🌅 매일 아침 1분 — 리스크 탭 훑기
- **risk-d**(평일 07:00 자동)가 밤사이 거시 충격을 점검해 리스크 탭에 신호를 남긴다.
- 🟢 정상이면 **그냥 닫는다.** 🟡 주의·🔴 경보만 펼쳐서 본다.
- 전형 예: "USDKRW 환율 극단값 상단(1,500) 초과 → 달러 자산 축소 검토", "미10년물 급등 → 채권·리츠 점검".
- **여기서 바로 팔지 않는다.** 경보는 *조기경보*일 뿐. 실제 행동은 매수평가/매도검토에서 결정.

### 📅 주 1회 (월요일 아침) — 논리점검 + 행동처방
1. **리스크 탭**: risk-b(월 07:10 자동)가 위탁 개별주식 9종목의 펀더멘털 논리훼손을 점검한 신호 확인.
2. **리포트 탭**: 주간 AI 리포트 상단 "🎯 이번 주 행동 처방"(딱 1가지)을 읽는다. 이게 이번 주 실행 항목.
   - 리포트는 **수동 생성**(Trading Agent 스킬) → 시트 적재는 자동. 안 만들면 안 갱신됨.

### 🤔 매수/매도 고민이 들 때 — 평가 먼저, 주문 나중 ★핵심
이 앱의 심장. 순서를 지킨다:
1. **매수평가 탭**에서 종목을 큐에 올린다(살까 검토) / **매도검토 탭**에서 "근거 점검"을 누른다(팔까 검토).
2. AI가 평가 카드를 생성(drain 3시간 주기 자동, 또는 수동).
3. **매도검토 탭**에서 카드를 읽고 **최초 매수 이유 대비 현재**를 비교.
4. 판정(🟢유효/🟡관망/🔴부적합)을 보고 **그 다음에** 실제 주문을 넣는다.
- 충동매매 방지 장치. "지금 사고 싶다 → 일단 큐에 넣는다"가 습관이 되게.

### 📊 월/회고 — KPI 탭
- TWR(시간가중수익률)·Sharpe·MDD(최대낙폭)로 성과를 객관적으로 본다.
- **행동추적**: 500만원 원칙(1종목 최대 비중)을 지켰는지, 평가→매수 일치율(평가 없이 산 건 없는지)을 점검.
- 수익률보다 **행동 습관**을 보는 탭.

### 💰 체결·배당이 발생하면 — 자동 (확인만)
- 증권사 카카오 알림 → 알람 탭 적재 → **15분 내** 체결내역/배당금 자동 반영.
- 할 일 없음. 체결/배당금 탭에서 들어왔나 확인만. 종목명이 이상하면 배당 탭에서 인라인 수정.

## 2. 탭별 사용법 (앱 순서대로)

각 탭: **언제 보나 · 무엇을 하나 · 읽는 법 · 팁/주의**

### 홈
- **언제**: 수시, 앱 열면 첫 화면.
- **무엇**: 총자산·평가손익·자산군 배분 요약.
- **읽는 법**: 전체 그림 한눈에. 색상으로 손익 방향.
- **팁**: 빠른 현황 체크용. 의사결정은 다른 탭에서.

### 리스크 ★
- **언제 쓰나**: **매일 아침 1분**. 무인 조기경보를 훑는 용도. 손대는 탭이 아니라 *보는* 탭.
- **무엇이 보이나**:
  - 요약 카드 3개: 🔴 경보 / 🟡 주의 / 🟢 정상 건수.
  - 신호별: **유형(D=거시 / B=논리)** · 대상(종목·지수) · 신호(🟢🟡🔴) · 요약 · 자세히(detail) · 근거(evidence) · 기준선참조.
  - **D(거시)**: risk-d가 평일 07:00 생성. 환율·금리·지수 충격 등 *일간 조기경보*.
  - **B(논리)**: risk-b가 월 07:10 생성. 위탁 9종목 펀더멘털 훼손 *주간 점검*. 리스크기준선(매출총이익·영익·ROE·부채·EPS) 대비 악화 감지.
- **읽는 법**: 🟢는 무시, 🟡🔴만 펼쳐 '자세히'·'근거' 확인.
- **주의**: 리스크 탭은 **신호만**(행동 권고 없음). 경보가 떠도 **바로 팔지 않는다** → 매수평가/매도검토에서 의사결정. 종합 판단·행동처방은 주간리포트가 이 신호를 재인용해 제공.

### 매수평가 ★ (구 "평가")
- **언제 쓰나**: **새 종목 매수를 검토할 때**, 또는 추가매수 전 "지금 사도 되나" 확인할 때.
  충동적으로 사고 싶을 때 **일단 여기에 넣는 것**이 핵심 습관.
- **무엇을 하나**:
  1. "평가 의뢰" 버튼 → 모달에서 **종목명 + 시장(KR/US) + (선택)메모** 입력 → "큐에 추가".
  2. 평가요청 큐에 `대기` 상태로 들어감 → drain(3h 자동)이 헤드리스 AI로 5축 평가 → 종목투자노트에 카드 적재.
- **읽는 법**:
  - 큐 상태 뱃지: `대기`(처리 전) · `처리중` · `완료` · `오류`.
  - 종목 칩에 최신 평가 등급 표시. 완료되면 **매도검토 탭**에서 카드 확인(평가했고 보유 중이면).
  - 5축: 수익성·안정성·밸류에이션·현금흐름·모멘텀 → 종합 🟢유효 / 🟡관망 / 🔴부적합.
- **주의**: 큐가 비면 아무 일도 안 함(자동 종목 추가 없음). 평가는 **내가 큐에 넣어야** 돌아간다.

### 매도검토 ★ (구 "노트")
- **무엇이 뜨나**: **평가 이력이 있고 + 현재 보유 중**인 종목만. (평가만 하고 안 산 종목, 전량 매도한 종목은 안 뜸)
- **언제 쓰나**:
  - **회고·근거 점검**: 내가 왜 이 종목을 샀는지, 그 이유가 아직 유효한지 볼 때.
  - **매도 검토**: 팔까 고민될 때 "근거 점검" 버튼으로 **매도평가**를 돌린다.
- **무엇을 하나 / 읽는 법**:
  - 종목 칩 클릭 → 보유 현황 + **최초 매수 근거**(1~3개) + 평가 이력 타임라인.
  - 상단 경보: RSI 과열(>70)·급락(<30)·52주 고점 근접(>80%) ⚠️. 마지막 평가 후 경과일(>30일 🟡, >90일 🔴).
  - **"근거 점검" 버튼** = 매도평가 트리거. 누르면 평가요청 큐에 `메모='매도 평가'`로 적재 → drain이 sell-evaluation 카드 생성.
    - *최초 매수 이유가 있어야* 활성화(없으면 비교 기준이 없어 비활성).
  - 매도평가 카드: **최초 ↔ 현재 ↔ 근거 점검 ↔ 리스크 점검 ↔ 판정 ↔ 권고 4안**(전량/절반/1/3/보유).
    - 판정: 🟢유효(근거 멀쩡) / 🟡관망 / 🔴부적합(논리 훼손) / ⚪판단보류(데이터 부족).
- **핵심 용도**: 매도 결정의 기준선. "샀을 때 이유가 깨졌나"를 보고 판다. 가격이 올라서/내려서가 아니라.

### 보유종목
- **언제**: 수시.
- **무엇**: 4계좌 통합 보유 현황(종목·수량·평균단가·수익률).
- **읽는 법**: 자산군별 색상. 수익률 정렬로 손실 종목 식별.

### 자산분배
- **언제**: 리밸런싱 판단 시.
- **무엇**: 계좌별(위탁/연금저축/ISA/IRP) 목표 vs 현재 비중, 리밸 갭.
- **읽는 법**: 목표% 대비 현재% 갭(+/-)이 크면 조정 후보.
- **주의**: 갭이 있다고 바로 매매하지 말 것. 갭 + 평가(펀더멘털)를 같이 본다.

### 리포트
- **언제**: 주 1회(월요일).
- **무엇**: 주간 AI 종합 리포트. 상단 "🎯 이번 주 행동 처방"(1가지) + 시장환경·진단.
- **읽는 법**: 행동 처방 1줄이 핵심. 나머지는 맥락.
- **주의**: **생성은 수동**(Trading Agent 리포팅 스킬 실행). 안 만들면 갱신 안 됨. 적재만 자동(매일 09:00 sync).

### KPI
- **언제**: 월/분기 회고.
- **무엇**: TWR·Sharpe·MDD + 행동추적(500만 원칙 준수·평가→매수 일치율).
- **읽는 법**: 성과 지표 + **습관 지표**를 같이. 평가 없이 산 종목이 있으면 행동추적에 잡힌다.

### 체결 / 배당금 / 수익금
- **언제**: 거래·배당 발생 후 확인.
- **무엇**: 체결내역(매수/매도)·배당 수령·실현손익.
- **읽는 법**: 자동 적재(15분 주기). 수동 개입 불필요.
- **팁(배당)**: 배당 탭은 **종목명 인라인 편집** 가능. 증권사 알림 종목명이 약칭/오타일 때 직접 수정.

## 3. 자주 하는 작업 (How-to)

### 새 종목 매수 검토
1. **매수평가 탭** → "평가 의뢰" → 종목명·시장 입력 → "큐에 추가".
2. 기다리거나(drain 3h) 수동 drain. 완료되면 **매도검토 탭**에서 카드 확인(보유 중이면).
3. 5축 종합 🟢이면 매수 후보, 🟡 관망/절반, 🔴 매수금지.

### 매도 판단
1. **매도검토 탭** → 해당 종목 칩 클릭 → "근거 점검" 버튼.
2. 매도평가 카드 생성 후, **최초 매수 이유가 깨졌는지** 확인.
3. 🔴부적합이면 권고 4안 중 선택, 🟢유효면 보유 유지(가격이 빠져도 논리가 멀쩡하면 안 판다).

### 배당 종목명이 틀렸을 때
- **배당 탭**에서 종목명 셀 인라인 편집. (증권사 알림 약칭/오타 보정)

### 리밸런싱 갭 확인
- **자산분배 탭** 목표% vs 현재% 갭 확인 → 갭 큰 자산군 + 평가(펀더멘털) 같이 보고 조정.

## 4. 데이터 흐름 · FAQ

전체 데이터 흐름·자동화 잡 정의는 [FEATURES.md](../FEATURES.md) 참조. 사용자 관점 FAQ만:

- **체결/배당이 바로 안 떠요** → 정상. 알람 탭 적재 후 parse-notifications(15분 주기)가 채운다. 최대 15분 지연.
- **평가가 안 돌아가요** → 큐가 비었거나 drain(3h) 차례가 안 됨. 또는 헤드리스 claude 사용량 한도(로그 확인).
- **매도검토 탭에 종목이 안 떠요** → 평가 이력이 있고 + 현재 보유 중인 종목만 뜬다. 평가만 하고 안 샀거나 전량 매도했으면 안 보임.
- **리스크 신호가 안 갱신돼요** → risk-d는 평일 07:00, risk-b는 월 07:10에만 실행. 사용량 한도 시 일부 실패 가능.
- **리포트가 갱신 안 돼요** → 생성이 수동이다. Trading Agent 리포팅 스킬을 돌려야 새 리포트가 생긴다.

## 5. 투자 원칙 리마인더

> 정본은 Trading Agent. 여기선 앱 쓰며 잊지 말 것만.

1. **펀더멘털 우선, 가격 후순위.** 52주 고점·RSI 과열만으로 익절하지 않는다.
2. **평가 먼저, 주문 나중.** 충동매매는 일단 매수평가 큐로.
3. **매도는 논리 훼손으로.** 매도검토의 "최초 매수 이유"가 깨졌을 때 판다. 가격 등락이 아니라.
4. **500만원 원칙.** 1종목 비중 한도. KPI 행동추적에서 점검.
5. **리스크 경보 ≠ 행동 지시.** 조기경보는 보는 것, 결정은 매수평가/매도검토에서.
