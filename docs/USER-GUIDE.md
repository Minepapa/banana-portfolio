# banana-portfolio — 실전 사용 가이드

> 각 탭을 언제·어떻게 쓰고, 자산 관리에 어떻게 녹이나에 집중한다.

---

## 1. 루틴 빠른 참조

이 앱은 결국 3가지 일을 한다: **① 충동 차단**(살까/팔까 충동을 평가 큐로 한 번 거르기) · **② 논리 감시**(매수 이유를 기록해두고 훼손 여부만 자동 추적) · **③ 자기 학습**(행동에서 성향을 익혀 다음 판단에 반영). 아래 루틴은 이 세 가지를 잊지 않기 위한 것.

| 타이밍 | 할 일 | 탭 |
|--------|-------|----|
| 매일 (앱 열면 첫 행동) | 오늘 할 일 체크리스트 | **오늘** |
| **주문서 도착 시 (텔레그램 푸시)** | 완성된 주문서 승인/기각 — 승인하면 증권사 앱에 그대로 입력만 | **주문** |
| 매일 아침 1분 | 거시 충격 경보 확인 | **리스크** |
| 주 1회 (월요일) | 논리점검 + 주간 행동처방 | **리스크 → 리포트** |
| **주말 (자동 리마인더)** | 리포트 처방 → 자산분배 갭 → 포지션 전제·교훈 정리 | **오늘 → 리포트** |
| **매월 1~5일 (자동 리마인더)** | 성과보다 행동습관(500만 원칙·평가→매수 일치율) 먼저 회고 | **오늘 → KPI** |
| 살까 고민이 들 때 | 평가 의뢰 먼저 (충동 차단) | **평가 [매수]** |
| 팔까 고민이 들 때 | 매수 근거가 깨졌는지 점검 | **평가 [매도]** |
| 경보 종목 점검 | 이탈조건 대조 | **포지션** |
| 월/분기 회고 | 성과·습관 점검 | **KPI** |

> **황금 원칙**: 가격(52주 고점·RSI 과열)만으로 사고팔지 않는다. **평가 먼저, 주문 나중.** 펀더멘털 우선.
> **가장 아까운 습관**: 5축 평가는 잘 만들어져 있어도 "그냥 사는" 게 더 쉽다. 시세 확인하러 앱을 열었다가 그대로 사지 말고, **평가 의뢰부터 누른다** — 오늘 못 사도 된다, 큐에 넣는 행위 자체가 충동을 끊는다.

## 2. 핵심 흐름 — 리스크 → 포지션 → 평가

세 탭이 연결되어 있어 혼동하기 쉽다. 역할 구분:

| 탭 | 한 문장 역할 | 여기서 할 수 있는 것 |
|----|-------------|---------------------|
| **리스크** | 자동 경보를 *읽는* 탭 | 없음. 읽고 다음 탭으로 넘긴다 |
| **포지션** | 투자논리·이탈조건을 *관리*하는 탭 | 이탈조건 편집, 교훈 기록 |
| **평가** | 매수/매도 *결정을 내리는* 탭 | 평가 의뢰, 매도평가 요청 |

### 경보가 떴을 때 의사결정 흐름

**오늘 탭 → 경보 항목 확인**
- 리스크 탭 이동: 신호 내용 확인 (읽기만)
  - B(논리훼손) 신호 → 포지션 탭: 해당 종목 이탈조건 대조
    - 이탈조건 충족됨 → 평가 탭 [매도]: "근거 점검" 실행
    - 이탈조건 미충족 → 이탈조건 업데이트 후 종료
  - D(거시충격) 신호 → 리포트 이번 주 처방과 연결해 생각

**살까 충동이 생겼다**
- 평가 탭 [매수] → 일단 큐에 넣는다 (충동매매 차단 장치)

### 핵심 규칙 3가지

- **리스크 탭은 읽기 전용이다.** 경보가 떠도 바로 팔지 않는다.
- **매도 결정은 포지션 탭이 아니라 평가 탭에서.** 포지션은 이탈조건 대조만.
- **평가 탭이 유일한 의사결정 관문.** 매수든 매도든 반드시 거친다.

## 3. 탭별 가이드

### 홈

언제·무엇: 수시. 앱 열면 첫 화면. 총자산·평가손익·계좌별 도넛·평가금 추이.
빠른 현황 확인용. 의사결정은 다른 탭에서.

**"어제 대비" 변동은 매일 08:00 KST에 자동으로 찍히는 잔고 스냅샷이 기준**이다(미국장 마감
후·한국장 개장 전 = 모든 종목이 직전 종가인 시점). 개별 종목의 변동 목록은 오늘 탭 하단
"오늘의 변동 종목"에서 확인한다(§ 오늘 참고).

---

### 판테온 — 지금 어느 부서가 뭘 하고 있는지

**언제**: 수시. 이 앱은 내부적으로 4개 부서(투자전략실·리스크관리실·운영실·비서실)가
각자 맡은 일을 처리하는 구조로 돌아간다. 판테온 탭은 대표의 한 줄 종합 + 부서별 현재
상황을 한 화면에 모은 현황판이다.

- **대표**: 4개 부서 상황을 종합한 한 줄 요약. 가장 급한 것 먼저(리스크 경보 > 잡 실패 >
  평가 오류 > 대기건 합산 순).
- **투자전략실**: 평가 큐 대기 건수 → "바로가기"로 평가 탭.
- **리스크관리실**: 감시 중 리스크 경보·주의 건수 → "바로가기"로 리스크 탭.
- **운영실**: 무인 잡(자동화) 점검 필요 건수 → "바로가기"로 KPI 탭.
- **비서실**: 다음 주간 리포트 D-day·성향 확인 대기 건수 → "바로가기"로 성향 탭.

같은 부서 배지가 리스크·평가·KPI·성향 탭 상단에도 붙어 있어, 어느 탭에 있든 "이건 어느
부서 일인가"가 항상 보인다. 판테온 탭은 그 4곳 상태를 한 화면에 모은 것뿐 — 별도 데이터나
새 판단 로직은 없다(각 탭의 숫자와 항상 일치).

---

### 오늘 — 매일 처리 허브

**언제**: 매일 앱을 열면 첫 행동.

오늘 탭이 흩어진 처리거리를 데이터에서 자동 집계해 한 화면에 모아준다. 없으면 "오늘 할 일 없음".

자동 집계 항목:
- **리스크 경보·주의**: 리스크 탭의 경보/주의 건수
- **투자논리 훼손 N종목**: 이탈조건 대조가 필요한 종목
- **미처리 체결 N건**: 동기화하면 보유종목에 반영
- **투자논리 확인 대기 N건**: AI 초안에 동의 표시 안 한 종목
- **반성 필요 N건**: 청산됐는데 교훈 미기록
- **리밸런싱 갭 N건**: 목표 비중 ±5%p 초과 자산군
- **이번 주 처방**: 최신 주간 리포트 행동처방 1줄
- **무인 잡 점검 N건**: 자동화 잡 실패·정체
- **성향 확인 대기 N건**: 관찰/승격후보 상태의 학습 성향
- **주간 정리 15분** (주말에만 표시): 리포트 처방 → 자산분배 갭 → 포지션 전제·교훈 정리
- **월간 회고 10분** (매월 1~5일에만 표시): KPI 행동추적을 성과보다 먼저 회고

탭 맨 아래에는 **"오늘의 변동 종목"**(할 일 목록과 무관, 참고용)이 붙는다. 매일 08:00 KST
잔고 스냅샷 대비 **등락률(%) 기준**으로 변동폭이 큰 종목 상위를 보여준다 — 금액이 아니라 %
기준이라 투자금이 작은 종목도 크게 흔들렸으면 상위에 뜬다. 매수·매도로 수량이 바뀐 종목은
"거래" 표시가 붙는다(가격 변동분만 계산해 거래 금액이 섞이지 않음).

각 항목의 "…보기" 버튼이 해당 탭으로 이동. 오늘 탭은 허브일 뿐, 실제 처리는 각 탭에서.
"확인" 버튼은 체크 표시로만 남는다(데이터는 유지, 당일만 유효). 단, 주간·월간 리마인더의
"확인"은 **그 주말·그 달 동안 유지**된다(매일 다시 뜨지 않음).

### 주문 — 신호를 실행 가능한 주문서로

**언제**: 텔레그램 "주문서 N건 도착" 푸시가 오면. (주 1회 일요일 + 급락 시 즉시)

리밸런싱 갭·급락 매수 기회·논리훼손·평가 결과가 각 탭에 흩어진 "정보"로 끝나지 않도록,
시스템이 **완성된 주문서**(계좌·종목·방향·수량·예상금액)로 변환해 이 탭에 모아준다.

주문서 카드 구성:
- **주문 내용**: "위탁 매도 현대차 3주 × ₩482,000 ≈ ₩1,446,000" — 증권사 앱에 그대로 입력 가능한 수준
- **제약 체크**: ✓예수금 충분 · ✓500만 원칙(확신 종목은 예외 라벨) · ✓확신 종목 보호 — 내 규칙을 안 깨는지 자동 검증
- **근거 체인**: 왜 이 종목인지 — 출처 신호·평가 등급·확신도·갭 기여가 사실 그대로 나열

처리 흐름:
1. **승인** → "실행 대기"로 이동. 증권사 앱에서 그대로 주문 입력.
2. 체결 알림이 도착하면 **자동으로 "실행완료"** 처리(직접 정리할 필요 없음).
3. **기각** → 사유 한 줄 입력(어떤 제안이 내 성향과 안 맞는지 학습 원료가 됨).
4. 미응답 주문서는 **7일 후 자동 만료** — 부담 없이 무시해도 됨.

원칙: 수량·금액은 시스템이 결정론으로 계산(추정 없음), AI는 후보 중 선별·근거 서술만.
**최종 실행 결정은 항상 나의 몫** — 자동 주문은 하지 않는다.

### 리포트

**언제**: 주 1회 (월요일).

주간 AI 종합 리포트. **"이번 주 행동 처방" 1줄이 핵심.** 나머지는 맥락.
일요일 08:00 자동 발행(weekly-report) → 시트·앱 리포트 탭 자동 반영.

### 리스크 — 읽기 전용

**언제**: 매일 아침 1분. 경보를 보는 탭, 행동하는 탭이 아니다.

신호 유형 (2026-07 임계값 실증+문헌 재검증 완료 — 근거는 `profile/kpi_baseline.md` §8 참고):
- **D (거시)**: risk-d가 평일 16:30(장마감 후) 생성. 환율·금리·지수 충격 일간 경보 — 전부 결정론(숫자만으로 강제 발동, AI 판단 없음):
  - KOSPI 5거래일 고점 대비 -10% 이하 ("시장 조정" 진입의 표준 기준과 동일 크기)
  - S&P 500 5거래일 고점 대비 -7% 이하 (미국 서킷브레이커 1단계와 동일 크기)
  - 원달러 5거래일 저점 대비 +3% 이상, 또는 12개월 변동 밴드(평균±2표준편차) 이탈
- **B (논리)**: risk-b가 월 03:00 생성. 위탁 보유 **개별주식만**(ETF·펀드 제외) 펀더멘털 훼손 주간 점검. 아래 중 하나라도 걸리면 최소 "주의"로 강제:
  - 영업이익(전년 동기 대비) 2분기 연속 감소
  - 부채비율(부채/자기자본) 200% 초과
  - 현금흐름 흑자→적자 전환
- **O (급락매수)**: 개별종목 급락 기회 포착. 5일 낙폭이 **그 종목 평소 변동성(ATR) 대비** 이례적으로 클 때, 또는 RSI 30 이하(과매도)일 때 발동 — 테슬라처럼 원래 변동이 큰 종목과 배당주를 똑같은 고정 %로 재지 않는다. MACD·이동평균·거래량 등은 신호가 뜬 뒤 근거를 보강하는 참고 문구일 뿐, 신호 발동 여부 자체는 안 바꾼다.

읽는 법: 정상이면 그냥 닫는다. 주의·경보만 펼쳐서 "자세히"·"근거" 확인.
**경보가 떠도 바로 팔지 않는다.** 행동은 평가 탭에서.

### 포지션 — 투자논리 관리

**언제**:
1. 리스크 탭 B 신호 확인 직후 → 해당 종목 이탈조건 대조
2. 새 보유종목 AI 초안 확인 → "확인" 버튼으로 동의 표시
3. 이탈조건 업데이트
4. 청산 후 교훈 한 줄 기록

카드에서 보이는 것: 투자논리 · 목표 · 이탈조건 · 예상보유기간 · 진입일 · 최근 점검일.

- **논거 훼손 경보 (빨강 테두리)**: 이탈조건과 대조해 평가 [매도]로 넘길지 판단.
- **이탈조건 편집**: 이탈조건 영역 롱프레스 → 인라인 편집.
- **투자논리 수정**: 내용 직접 편집 가능. 짧아도 된다.

**여기서 매도 결정을 내리지 않는다.** 이탈조건 충족 여부 판단만. 충족됐으면 평가 탭으로.

### 평가 — 유일한 의사결정 탭

**상단 [매수][매도] 토글**로 전환. 매수든 매도든 주문 전 반드시 이 탭을 거친다.

**[매수] 모드 — 살까 검토할 때**

1. "평가 의뢰" 버튼 → 종목명·시장(KR/US) 입력 → 큐에 추가.
2. drain(하루 7회: 1·4·9·12·14·19·22시)이 카드 생성.
3. 5축 종합 판정 확인: 수익성·안정성·밸류에이션·현금흐름·모멘텀.
   - **유효**: 매수 후보 / **관망**: 절반 진입 / **부적합**: 매수금지

숫자는 코드가, 판단은 AI가: PER·ROE(TTM)·RSI·52주 위치·PBR·영익률·FCF yield 등을 코드 페처(pykrx·yfinance·OpenDart)가 직접 산출해 카드에 주입한다. AI는 5축 판단만 한다.

**[매도] 모드 — 팔까 점검할 때**

- 평가 이력이 있고 + **현재 보유 중**인 종목만 뜬다.
- 종목 칩 클릭 → 보유 현황 + 최초 매수 근거 + 이력 타임라인.
- 논거 훼손 경보(빨강): 포지션·오늘 탭과 동일 소스.
- 기술적 신호(노랑): RSI 과열·급락·52주 고점. **참고용** — 이것만으로 팔지 않는다.
- "근거 점검" 버튼 → 매도평가 큐 적재 → drain이 sell 카드 생성.

**핵심 질문**: 처음 샀을 때의 이유가 지금도 유효한가? 논리가 깨졌을 때 판다.

---

### 보유종목

수시 확인. 4계좌 통합 보유 현황(종목·수량·평균단가·수익률).
해외주식 평균단가는 USD, 국내는 KRW.

### 자산분배

리밸런싱 판단 시. 계좌별(위탁/연금저축/ISA/IRP) 목표% vs 현재% 갭.
현금성 예수금은 비중에서 제외(자산군 100% 기준).
갭이 있다고 바로 매매하지 말 것 — 갭 + 펀더멘털을 같이 본다.
오늘 탭 '리밸런싱 갭' 항목에서 갭 목록을 한 번에 볼 수 있다.

### 체결 / 배당금 / 수익금

거래·배당 발생 후 확인. 자동 적재(15분 주기).

- **체결**: 해외주식은 $, 국내는 ₩. 셀 미완성 행은 롱프레스로 편집.
- **배당**: 종목명 인라인 편집 가능(증권사 약칭·오타 보정).
- **수익금**: 해외주식 수익금 합계는 KRW(×환율 환산). 단가는 USD.

### KPI

월/분기 회고. TWR·Sharpe·MDD + 행동추적(500만원 원칙·평가→매수 일치율) + 무인 잡 상태.
**성과보다 행동 습관을 보는 탭.** 평가 없이 산 종목이 있으면 여기서 잡힌다.

### 성향

수시 확인. 시스템이 행동·대화에서 학습한 성향 관찰 목록.
관찰/승격후보 상태를 확인하고 **[확정]** 또는 **[기각]**으로 결정한다.
확정된 성향만 AI 평가 프롬프트에 반영된다.

## 4. 자주 하는 작업

### 새 종목 매수 검토
1. **평가 탭 [매수]** → "평가 의뢰" → 종목명·시장 입력.
2. drain 완료 대기(최대 몇 시간) 후 카드 확인.
3. 유효이면 매수 후보, 관망이면 절반 진입, 부적합이면 매수금지.

### 매도 판단
1. **오늘 탭** → "투자논리 훼손 N종목" 항목 → **포지션 탭**.
2. 경보 종목 카드 펼쳐 이탈조건 대조 → 충족 여부 판단.
3. 충족됐으면 **평가 탭 [매도]** → 종목 칩 → "근거 점검" 버튼.
4. 매도평가 카드에서 최초 매수 이유가 깨졌는지 확인.
5. 부적합이면 매도. 유효이면 보유 유지(가격이 빠져도 논리가 멀쩡하면 안 판다).

### 이탈조건 편집
**포지션 탭** → 해당 종목 카드 → 이탈조건 영역 롱프레스 → 인라인 편집.

### 배당 종목명 수정
**배당 탭** → 종목명 셀 직접 편집(증권사 약칭/오타 보정).

### 리밸런싱 갭 처리
**자산분배 탭** → 갭 큰 자산군 확인 → 펀더멘털도 같이 보고 조정 여부 결정.

## 5. FAQ

### 체결·배당

**체결·배당이 바로 안 떠요**
정상. parse-notifications가 15분 주기로 실행된다. 최대 15분 지연.

**해외주식 단가가 이상해요**
단가는 USD, 합계는 KRW(×환율)가 정상. 체결가는 $ 표시.

---

### 평가

**평가가 안 돌아가요**
drain이 하루 7회(1·4·9·12·14·19·22시) 실행된다. 큐가 비었거나 차례가 안 됐을 수 있다. 헤드리스 claude 사용량 한도 초과 시 KPI 탭 무인 잡 상태를 확인.

**평가 [매도]에 종목이 안 떠요**
평가 이력이 있고 + 현재 보유 중인 종목만 뜬다. 평가만 하고 안 샀거나 전량 매도했으면 안 보인다.

**평가 카드에 "(데이터 부족)"이 떠요**
정상. 숫자는 코드 페처가 산출하는데 해당 지표를 못 구하면 AI가 추정하지 않고 "(데이터 부족)"으로 표기한다. 종목코드·티커 매핑 실패 시 그 축 전체가 빠진다.

**아직 안 산 종목(관심종목)을 평가하고 싶은데 계속 오류가 나요**
국내 종목은 자동 매핑되지만, **미국 종목은 보유 중이 아니면 티커가 미리 등록돼 있어야** 한다(추정으로 매핑하지 않는 원칙). 매핑이 없으면 평가요청 상태가 즉시 "오류"로 표시된다 — 새 미국 관심종목을 평가하려면, 큐에 넣기 전에 먼저 (Claude 채팅으로) 티커 등록을 요청한다.

**같은 종목인데 탭마다 판정이 달라 보여요**
논거 훼손 경보는 평가[매도]·포지션·오늘 탭 모두 동일 소스다. RSI/52주 '기술적 신호'는 별도 박스라 혼동 없음.

**리스크 신호가 갱신 안 돼요**
risk-d는 평일 16:30, risk-b는 월 03:00에만 실행된다. 사용량 한도 시 일부 실패 가능(KPI 잡 상태 확인).

주 1회 스냅샷. 중간 거시 충격은 risk-d(매일 16:30)가 잡는다. 개별 펀더멘털은 분기 단위로 변하므로 주 1회로 충분.

### 의사결정

**경보가 떴는데 바로 팔아야 하나요**
아니다. 경보는 조기경보. 포지션 탭에서 이탈조건과 대조한 뒤, 충족됐으면 평가 탭 [매도]로 넘긴다.

**포지션 탭에서 논거 훼손인데 여기서 팔면 안 되나요**
포지션 탭은 이탈조건 대조 탭. 매도 결정은 평가 탭에서. 흐름: 리스크 경보 → 포지션 이탈조건 대조 → 평가 [매도] 근거 점검.

## 6. 투자 원칙 리마인더

> 정본은 투자자 프로필(profile/investor-profile.md). 여기선 앱 쓰며 잊지 말 것만.

1. **펀더멘털 우선, 가격 후순위.** 52주 고점·RSI 과열만으로 익절하지 않는다.
2. **평가 먼저, 주문 나중.** 충동매매는 일단 평가 [매수] 큐로.
3. **매도는 논리 훼손으로.** 최초 매수 이유가 깨졌을 때 판다. 가격 등락이 아니라.
4. **분할매수 원칙.** 자산분배 트랙의 실제 매수·매도 제안 크기는 5/25 밴드 갭(또는
   거시틸트 여유폭)의 최대 50%로 시스템이 강제 캡한다(`CAP_FRACTION`,
   `scripts/lib/allocation-proposal-shared.mjs`) — "500만원"은 이 캡과 무관한 별개
   지표로, 실제 매수 체결금액이 건당 500만원을 넘는지만 관찰하는 행동추적 KPI다
   (2026-09-06 정정 — 예전엔 이 500만원이 "1종목 비중 한도"인 것처럼 서술돼 있었으나
   1종목 비중 한도라는 규칙 자체가 코드에 없다).
5. **리스크 경보 ≠ 행동 지시.** 경보는 보는 것, 결정은 평가 탭에서.
6. **순서를 지킨다.** 리스크 확인 → 이탈조건 대조 → 평가 탭 의사결정.
