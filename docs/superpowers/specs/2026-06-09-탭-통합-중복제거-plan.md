# 탭 통합·중복 제거 구현 계획

작성일: 2026-06-09
대상: `src/App.jsx` (단일 파일)

## 목표

현재 6개 액션 탭(리포트·리스크·매수평가·매도검토·거래결정·포지션)에 흩어진 중복 기능을
의사결정 흐름(상황인식 → 대상발굴 → 결정·기록 → 회고)에 맞춰 4탭 + 홈으로 통합한다.

## 용어 결정

- **thesis → 투자논리** 로 통일. 경보는 **"논거 훼손 경보"**.
- 현재 UI는 "전제"라는 단어를 씀 → 전부 "투자논리"로 교체.
- 코드 내부 변수명 `thesis`/`findThesisAlerts`는 그대로 유지(비-사용자 노출, 리네임 리스크 회피).

## 최종 탭 구조

| 탭 | 역할 | 출처 |
|----|------|------|
| 홈 (dashboard) | 계좌 요약 + **계좌 비중 도넛(신규 이동)** + 평가금 추이 | 기존 + 리포트 도넛 |
| 리포트 (report) | 주간 AI 리포트 본문 읽기 전용(슬림화) | 기존에서 래퍼 카드 제거 |
| 리스크 (리스크) | 리스크 신호 상세 + 펀더멘털 기준선 (드릴다운) | 그대로 |
| 평가 (평가) | **매수/매도 토글 통합** | 매수평가 + 매도검토 |
| 거래결정 (거래) | 집계 허브 — 논거 경보·처방·리밸 갭·교훈 한 곳 | 기존 + 리포트 리밸 카드 흡수 |
| 포지션 (저널) | 투자논리/이탈조건/반성 기록 원본 | 그대로 (용어만 교체) |

제거되는 탭: **매도검토(노트)** → 평가 탭 매도 모드로 흡수.

## 중복 제거 매핑

| 중복 항목 | 현재 위치 | 통합 후 |
|-----------|-----------|---------|
| 논거 훼손 경보 | 리포트·거래·포지션 | 거래(읽기) + 포지션(편집)만 |
| 이번 주 행동 처방 | 리포트·거래 | 거래만 |
| 리밸런싱 신호 | 리포트·거래(버튼) | 거래(인라인 목록) |
| 포트폴리오 총괄 도넛 | 리포트 | 홈 |
| 5축 평가카드·매수근거·aiNote | 매수평가·매도검토 | 단일 컴포넌트 재사용 |
