# 달러RP 자동반영 (앵커+델타, 모델 X) — 설계

> 목적: 해외주식 매수·매도와 환전이 위탁 달러RP(위탁!8행)에 자동 반영되게 한다.
> 국내 예수금과 동형의 **기준선 + 거래 델타** 패턴. 단 **내부는 USD로 관리**하고
> 원화 표시는 `설정!B2`(라이브 환율) 수식으로 파생시킨다(모델 X).

## 배경 / 문제

- 현재 위탁!8 외화 RP는 원화 리터럴(수량1 × 1,050,000)로 **수동 관리**. 환전·해외매매가
  자동 반영 안 됨.
- 해외주식 체결 알람은 `수량 × USD단가`만 있고 **환율·원화금액이 없다**(원문 확인).
  → US 거래를 원화로 깎으려면 환율이 필요한데, 라이브 환율로 매시간 환산하면
  거래가 없어도 달러RP가 출렁임(멱등성 깨짐).
- 환전 알람엔 `외화금액 : USD N`이 있고, 해외 체결도 USD 단위. **모든 흐름이 원래 USD**.

## 핵심 결정 (모델 X)

**달러RP를 USD로 관리**하면 환산이 아예 불필요하고 멱등이 자연스럽다.
원화 표시값은 `설정!B2`(USD/KRW 라이브 환율, 수식) 곱으로 파생 → 환율 따라 실시간.

```
USD잔액 = 기준USD + Σ(USD 델타, 날짜 > 기준일)
  · 환전 외화매수 → +외화금액(USD)
  · 환전 외화매도 → −외화금액(USD)
  · 해외 매수     → −(수량 × USD단가)
  · 해외 매도     → +(수량 × USD단가)
  · US 배당(USD)  → 현재 없음(YAGNI)
원화표시 = USD잔액 × 설정!B2  (시트 수식, 파서 안 건드림)
```

파서는 **위탁!D8(USD 잔액)만 리터럴**로 쓴다. C·E·F·H는 수식 보존.

## 데이터 모델

### 신규 시트 `달러기준` (예수금기준과 동형, USD 단위)

| 열 | 의미 | 채우는 주체 |
|----|------|------------|
| A 계좌 | 계좌탭(위탁) | 시드 |
| B 기준USD | 기준 시점 USD 잔액 | 사용자(앱/시트) |
| C 기준일 | yyyy-MM-dd | 사용자(앱이 오늘로) |
| D 갱신시각 | 마지막 기록 시각 | 앱/파서 |

- `ensureSheet`로 보장. 시드 `[['위탁', 736, todayKST, nowStr]]`.

### 표시행 위탁!8 재구성 (모델 X, 1회 셋업)

| 셀 | 값 | 비고 |
|----|----|----|
| D8 수량 | USD 잔액 | **파서가 리터럴로 씀** |
| C8 단가 | `=설정!B2` | 라이브 환율 |
| F8 현재가 | `=설정!B2` | 라이브 환율 |
| E8 투자금 | `=D8*C8` | = 원화 |
| H8 평가 | `=D8*F8` | = 원화 |

→ 손익 G8=H8−E8=0, 수익률 0%. 현금성 유지. 평소 보는 값은 원화(라이브).

## 파서 변경 (parse-notifications.mjs)

### 1. 환전 파서 추가
- 알람 `환전내역 안내` 매칭. 필드: 환전일자(MM월 DD일), 환전구분(외화매수/매도),
  통화명(USD), 외화금액(USD N). 날짜는 기존 연도추론 로직 재사용.
- dedup 키: `날짜|구분|USD금액`.

### 2. USD 체결 라우팅
- 기존 `execs`에서 `currency==='USD'`를 (현재 line 452에서 skip) → 달러 델타로 보냄.
- 매수 −(수량×단가), 매도 +(수량×단가). 종목 무관, 위탁 계좌 단일.

### 3. 달러RP 잔액 계산·쓰기
- `달러기준` 로드 → baseUSD, baseDate(빈칸이면 skip + 경고).
- `USD잔액 = baseUSD + Σ(USD델타, 날짜>기준일 strict)`.
- 위탁!D8 = USD잔액 (updateCell). C·E·F·H 보존.
- `--dry-run` 계산만 출력.

### 멱등성
환전·USD체결을 매 회차 알람에서 재수집(dedup) + 기준 이후만 가산 → 재실행 동일.
환율 변동은 표시수식(설정!B2)만 움직이고 저장 USD는 불변 → 출렁임 없음.

## 앱 변경 (src/App.jsx)

- `isDollarRow(h)`: `h.name === '외화 RP'` && acctKey==='위탁'.
- `startLP`에서 isCashRow 분기 다음에 isDollarRow 분기:
  `setEditingDollar({origIdx, sheetRow})`, 초기값 = 현재 USD(h.qty).
- 패널(editingDollar): 입력 1개 **USD 잔액**. 안내 "USD 잔액을 오늘 기준으로 리셋.
  이후 환전·매매 자동 가감."
- `saveDollar`:
  1. `달러기준!A`에서 '위탁' 행 찾기(없으면 append 시드).
  2. `달러기준!B:C` = `[USD, todayKST]`.
  3. 위탁!D8 = USD (표시행 즉시 반영).
  4. `sheets.fetch()`.
- saveCash와 동일 메커니즘. C·E·F·H 수식 안 건드림.

## 엣지 케이스
- 기준 빈칸/NaN → 표시행 skip(경고). 입력 전까지 현재값 보존.
- USD 음수/NaN 입력 → 저장 막고 안내. 0 허용.
- 환전 알람 현재 0건 → 파서 안전하게 0 델타(기준만).
- 환전이 KRW 위탁예수금에 주는 영향 → NH 출금가능금액 앵커가 자체 교정. **범위 밖**.
- US 배당(USD) → 현재 없음. 후속.

## 셋업 (1회)
- `달러기준` 시드(736 USD).
- 위탁!8 C·E·F·H 수식 설정 + D8=736. setup 스크립트 또는 앱 첫 저장.

## 테스트 전략
- 빌드·린트 통과.
- 파서 `--dry-run`: 기준 736/오늘 → US 체결 기준 이후 0 → `736 + 0 = 736 USD` 출력.
- 멱등: 같은 알람 2회 → 동일.
- 앱(로그인): 외화 RP 길게 눌러 USD 패널, 저장 후 달러기준 갱신 + D8 반영, 파서 재실행 원복 없음.

## 범위 밖 (YAGNI)
- US 배당(USD) 처리.
- 환전→KRW 예수금 동시 반영(NH 앵커가 교정).
- 다계좌 달러RP(현재 위탁 단일).
