# v1 이력은 전체 변환한다 — Vault 분류체계의 "새 출발점" 원칙은 데이터에는 적용 안 됨

Vault의 4대 분류(Facts/State/Decisions/Knowledge)를 설계할 때 "기존 폴더명에 얽매이지
않고 새 체계로 정리하는 것이 출발점"이라고 정했다. 이 원칙을 그대로 데이터에도 적용하면
v2가 빈 Vault로 시작하고 과거 이력은 v1 시트에만 남는 것처럼 보일 수 있다.

하지만 이건 **분류 구조(폴더명·조직 원칙)에 대한 결정이지, 실제 과거 데이터를 버린다는
뜻이 아니다.** 특히 지금 보유 중인 종목의 매수 근거를 새로 시작하면 "매도평가 시 최초
매수 이유와 비교"라는 기존 핵심 기능이 무력화된다. 그래서 v1의 체결·배당·수익금·
평가노트·포지션저널·리포트·성향관찰 등 전체 이력을 새 Vault taxonomy에 맞는 파일로
변환하기로 확정했다(매핑표는 "v1 → v2 마이그레이션 계획" 절 참고). 컷오버 후 v1
launchd 잡은 중단하되, 구글시트 자체는 삭제하지 않고 읽기전용 아카이브로 무기한
보존한다 — 비용이 안 들고, 변환 오류 발견 시 원본 대조가 가능해야 하기 때문이다.

**고려했던 대안**: 현재 상태(보유종목·자산분배)만 이관하고 과거 체결·배당 이력은
변환하지 않은 채 v1 시트에만 남겨두는 절충안 — 엔지니어링 비용은 훨씬 적지만, "옵시디언에
모든 기록이 있어야 한다"는 이번 재설계의 핵심 원칙과 어긋나 오너가 명시적으로 전체 변환을
선택했다.

**여파**: 마이그레이션 스크립트가 일회성이지만 상당한 분량의 시트 탭을 다뤄야 하고,
변환 후 수치 대조 검증이 필수다(개인 재무 데이터의 조용한 변환 오류가 가장 위험한
실패 모드).
