# Obsidian Vault를 유일한 기록 원본으로, 구글 스프레드시트는 폐기

v1은 구글 스프레드시트를 체결·배당·평가·리포트 등 모든 기록의 정본으로 썼다. v2는 이
역할을 완전히 Obsidian Vault로 옮기고 스프레드시트를 데이터 저장소 용도에서 폐기한다.
"앱에 안 보이는 것도 다 기록으로 남아야 한다"는 오너의 원칙과, 이 리포지토리가 퍼블릭이라
계속 시트를 정본으로 쓰면 개인 재무 데이터가 코드와 뒤섞일 구조적 위험이 있다는 점 때문에
처음부터 완전히 분리하기로 했다.

**고려했던 대안**: 시트를 비공개로 전환해 유지 — 이미 GitHub Pages 배포와 얽힌 OAuth
인증 흐름을 다시 설계해야 해서 기각.

**여파**: Firestore가 대시보드 전용 파생 캐시로 신설돼야 하고, 카카오 알림 파싱 등 기존
시트 기반 자동화 전체가 쓰기 대상을 Vault로 바꿔야 한다.
