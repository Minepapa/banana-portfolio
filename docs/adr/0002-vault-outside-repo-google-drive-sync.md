# Vault는 git 리포 밖 독립 경로에, Mac↔안드로이드는 Google Drive 폴더 동기화

Vault가 개인 재무 데이터의 유일한 원본이 되면서, 물리적으로 어디에 둘지와 Mac + 갤럭시
(안드로이드) 두 기기에서 어떻게 열람할지 정해야 했다. 이 git 리포지토리·기존 Trading
Agent 허브와도 완전히 분리된 새 독립 경로에 Vault를 두고, Mac은 "Google Drive for
desktop"으로 로컬처럼 마운트된 폴더 안에서 쓰고, 안드로이드는 별도 동기화 앱
(FolderSync·Autosync 등)으로 연결하기로 했다.

퍼블릭 리포에 재무 데이터가 섞이는 구조적 위험을 원천 차단하고, 아이폰이 아닌 갤럭시라
iCloud 계열 동기화가 애초에 선택지가 아니어서, 이미 쓰고 있는 구글 계정을 재사용하는
무료 경로를 택했다.

**고려했던 대안**: Obsidian Sync(공식 유료 서비스, 충돌 처리가 더 안전함) — 매달 비용이
드는 것 대비 지금 단계에서는 무료 대안으로 충분하다고 판단해 기각(2026-07-28 기준,
나중에 충돌 문제가 실제로 반복되면 재검토 여지 있음).

**여파**: Google Drive 동기화는 백업이 아니라 단순 복제라는 점을 별도로 인지해야 하고
(critic 리뷰 TIER 1 지적 — 별도 백업 체계 필요), State 파일 동시쓰기 충돌 위험도 관리
대상이다(구현 메모에 완화안 기록됨).
