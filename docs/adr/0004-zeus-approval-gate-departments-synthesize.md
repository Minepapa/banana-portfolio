# Zeus는 승인 게이트로 역할 축소, 종합은 부서(주로 Athena) 몫

기존 `.claude/agents/PANTHEON.md` 헌장은 Zeus가 부서 산출물을 비판적으로 검토·종합해
최종 결정하는 것까지 Zeus의 일로 명문화하고 있었다. 오너는 v2 설계에서 "Zeus는 의자에
앉아 하나하나의 안건을 판단·결정만 하고, 종합하고 모으고 안건을 올리는 건 부서가 해야
할 일"이라며 이 역할 분담을 의도적으로 재설계할 것을 명시적으로 요청했다.

그래서 5부서(Hermes·Kairos·Athena·Themis·Apollo)는 수평 동등한 위치에서 각자 소관
안건을 직접 종합해 Zeus에게 올리는 것을 기본으로 하고, 매수/매도·주문·평가 등 투자실행
안건만 예외로 "투자실행협의체"(Hermes→Kairos→Athena→Themis 순으로 종합이 이어지는 특별
절차)를 거쳐 Zeus에게 도달하도록 확정했다. Zeus는 이미 완성된 안건의 승인/반려만 한다.

여러 부서가 걸치는 애매한 안건에서 Zeus가 직접 알아보러 다니는 상황 자체를 설계 결함으로
보고, 담당을 명확히 해 Zeus의 판단 부담과 매 안건마다의 조사 비용을 줄이기 위함이다.

Zeus 몫으로 명문화됨)이 이 결정과 정면으로 어긋난다 — 구현 단계에서 헌장 개정이 필요하다.
