# 매수/매도 승인은 텔레그램 인라인 버튼이 아니라 텍스트 답장으로

처음엔 매수/매도 제안에 인라인 버튼(승인/거부)을 붙이는 것으로 설계했다. 그러나 실제
설치된 텔레그램 플러그인(`~/.claude/plugins/.../telegram/server.ts`) 코드를 조사한 결과,
`InlineKeyboard`/`callback_query`는 Claude Code 자체의 "이 도구 실행해도 될까요?" 권한
요청(harness의 `permission_request` 알림) 전용으로만 배선돼 있고, 어시스턴트에 노출된
도구는 `reply`(텍스트+파일)·`react`(고정 이모지)·`edit_message` 3개뿐이라 임의 비즈니스
버튼을 보낼 수 없다는 걸 확인했다.

그래서 Frank가 제안 메시지에 `reply_to`로 "승인"/"거부" 텍스트를 답장하면 상시 텔레그램
세션이 해석해 처리하고, 처리 후 원본 제안 메시지를 `edit_message`로 갱신해 상태를
반영하는 방식으로 재확정했다. 지금 인프라로 새 개발 없이 바로 구현 가능하기 때문이다.

**여파**: `reply_to` 없는 애매한 답장의 처리 규칙(예: "가장 최근 미처리 제안"으로 추정할지
아예 거부할지)을 명확히 정해야 한다 — critic 리뷰는 오귀속 위험 때문에 이런 폴백 추정을
아예 금지할 것을 권고했다(다음 세션 안건). 버튼이 정말 필요해지면 플러그인 확장이나 별도
봇 프로세스 신설이 필요하다.
