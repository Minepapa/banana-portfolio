# Trading Agent 허브를 은퇴시키고 전략 정본을 새 Vault로 완전 이관

새 Vault의 Knowledge/Playbook에 전략 원칙(펀더멘털 기준·매수매도 원칙 등)을 담기로
하면서, 기존 Trading Agent 허브(`profile/playbooks/learning/skills`, 오너의 메모리
체계가 투자 철학의 정본으로 간주해오던 곳)와 정본이 두 곳으로 갈라지는 문제가 critic
리뷰에서 지적됐다. 같은 성격의 내용이 두 곳에서 각자 갱신되면 드리프트가 생긴다.

전략 원칙의 정본을 **새 Vault Knowledge로 완전히 이관**하고 **기존 허브는 은퇴**시키기로
확정했다 — "옵시디언에 모든 기록이 있어야 한다"는 이번 재설계의 핵심 원칙과 가장
일치하는 선택이다.

**고려했던 대안**: 허브를 정본으로 유지하고 Vault Knowledge는 참조(링크)만 — 다른
시스템이 이 허브를 계속 쓰고 있을 가능성을 보호할 수 있지만, "왜 투자 기록이 두 군데
흩어져 있나"는 이번 재설계의 출발점 자체를 다시 어기게 돼 기각.

**여파**: banana-portfolio 외에 이 허브를 참조하는 다른 시스템(예: Trading Agent 자체)이
있다면, 그 쪽도 별도로 이관하거나 새 Vault를 가리키도록 조정해야 한다 — 실제 마이그레이션
실행 단계에서 반드시 먼저 확인할 사항. 확인 없이 허브 파일을 삭제하면 안 된다.
