# 카카오 알림 파이프라인은 구글시트를 임시 중계소로 유지, 안드로이드 앱은 변경 없음

Vault가 데이터 정본이 되면서 카카오 알림 원문이 폰→Mac으로 넘어가는 통로도 시트가 아닌
방식(예: Google Drive 동기화 폴더에 파일로 직접 씀)으로 바꿀 수 있었지만, 그러려면 별도
리포지토리인 Kakao-Notification 안드로이드 앱을 수정해야 한다.

그래서 안드로이드 앱은 그대로 두고 구글시트 "알람" 탭에 원문을 계속 적재하게 하되, 그
시트의 위상을 "데이터 정본"에서 "폰→Mac 임시 우편함"으로 재정의했다. Mac 로컬 자동화가
v1의 검증된 정규식 파서(NH·삼성·한국투자 브로커별, 체결/배당/펀드적립/금현물/예수금/환전
6종)를 그대로 이식해 Vault Facts/Ledger에 영구 기록하고, 처리된 시트 행은 정리한다.

안드로이드 앱을 건드리지 않고도 Vault-정본 원칙을 지킬 수 있고, 장기적으로 한국투자증권
(KIS) API로 계좌가 이관되면 이 파싱 파이프라인 자체의 비중이 자연히 줄어들 것으로 예상돼
지금 과잉 리엔지니어링하지 않기로 했다.

**고려했던 대안**: 안드로이드 앱이 Drive 동기화 폴더에 직접 쓰도록 수정 — 별도
리포지토리 수정 비용과 안드로이드 Drive API 연동 복잡도 때문에 후순위로 미룸.

**여파**: 구글시트는 "카카오 알림 앱이 자체 회전시키는 휘발성 우편함"이라 처리가 늦어지면
데이터가 영구 유실될 수 있다 — 촘촘한 처리 주기(매시간)와 Mac이 그 시간 안에 깨어있어야
한다는 전제가 깔린다. Mac이 잠들어 있는 동안 알림이 회전 삭제되는 시나리오는 아직 해소되지
않았다(critic 리뷰 TIER 1 — Mac 단일장애점·수면 시 데이터 유실 지적과 직결, 다음 세션
안건).
